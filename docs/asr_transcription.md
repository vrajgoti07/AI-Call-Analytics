# Automatic Speech Recognition (ASR) Module — Phase 3

## Overview

The Automatic Speech Recognition (ASR) module ingests standardized audio generated by the Phase 2 Preprocessor (`16 kHz, mono, PCM_16 WAV`) and produces structured, timestamped transcriptions powered by **faster-whisper** (CTranslate2).

It is specifically designed for conversational customer call analytics, delivering:
- Word-level and segment-level timestamps
- Automatic language identification and confidence scoring
- Real-time factor (RTF) performance metrics
- Monotonicity checks and hallucination/repetition loop diagnostics
- A future-proof data contract engineered for Phase 4 (Speaker Diarization)

## Configuration Settings

ASR configuration is managed via `WhisperConfig` and can be configured through environment variables or code:

| Setting | Env Variable | Default | Allowed Values | Description |
|---|---|---|---|---|
| `model_size` | `WHISPER_MODEL_SIZE` | `base` | `tiny`, `base`, `small`, `medium`, `large-v3` | Model complexity and accuracy tier |
| `device` | `WHISPER_DEVICE` | `auto` | `auto`, `cpu`, `cuda` | Hardware execution target |
| `compute_type` | `WHISPER_COMPUTE_TYPE` | `auto` | `auto`, `int8`, `float16`, `float32` | Weight quantization / precision |
| `language` | `WHISPER_LANGUAGE` | `auto` | `auto`, `en`, `es`, `fr`, `de`, etc. | Language code or auto-detection |
| `beam_size` | `WHISPER_BEAM_SIZE` | `5` | Integer >= 1 | Beam search width |
| `vad_filter` | `WHISPER_VAD_FILTER` | `False` | `true`, `false` | Voice activity detection filter |
| `word_timestamps` | `WHISPER_WORD_TIMESTAMPS` | `True` | `true`, `false` | Extract word-level timestamp alignments |

### Model Tradeoffs

* **`tiny` (39M params):** Ultra-fast (~30-75ms latency per 10s audio), ideal for local development, CI testing, and fast-path triage.
* **`base` (74M params):** Great default balance for desktop/laptop CPU workloads.
* **`small` (244M params):** Higher accuracy on conversational turns and diverse accents.
* **`medium` / `large-v3` (769M / 1550M params):** Production-grade accuracy for complex customer service vocabulary (requires GPU recommended).

## Device & Compute-Type Fallback Strategy

Faster-whisper relies on CTranslate2. The module automatically resolves hardware capabilities:
1. **Device Resolution:**
   - If `device="auto"`: checks for CUDA GPU device count and verifies that cuBLAS 12 libraries (`cublas64_12.dll`) are discoverable. If present, activates `cuda`; otherwise safely defaults to `cpu`.
   - If `device="cuda"`: strictly verifies CUDA availability and raises `UnsupportedRuntimeError` with informative remediation steps if GPU or cuBLAS libraries are missing.
2. **Compute-Type Resolution:**
   - On `cuda`: defaults to `float16` (or `int8_float16` / `float32` if supported).
   - On `cpu`: defaults to quantized `int8` (fast, memory-efficient integer arithmetic) or `float32`. Float16 on CPU automatically falls back to `int8`.

---

## Conversational VAD Policy

Voice Activity Detection (`vad_filter`) defaults to `False`.
In customer call analytics, conversational pauses, hesitations ("uh", "um"), and hold periods contain critical acoustic metadata for escalation risk and sentiment analysis. Aggressively removing pauses disrupts timing synchronization. If enabled, it uses Silero VAD with `min_vad_silence_ms=500`.

### Phase 4 (Speaker Diarization) Contract Compatibility

Every `TranscriptSegment` contains an optional `speaker: str | None = None` attribute.
In Phase 4, the speaker diarization pipeline will match speaker turns (`SPEAKER_00`, `SPEAKER_01`) directly against the segment and word time intervals without requiring any breaking schema changes or re-transcription.

## Quality & Anomaly Diagnostics

The ASR module audits transcription results for potential anomalies:
1. **Timestamp Monotonicity:** Flags backwards jumps, negative timestamps, or intervals exceeding audio file duration.
2. **Repetition Loops:** Detects hallucination loops where identical phrases repeat $\ge 3$ times.
3. **Empty Speech:** Detects audio files with significant duration (>1s) that yielded empty text.
4. **Low Confidence:** Flags recordings where majority of segments have `no_speech_prob > 0.6`.
